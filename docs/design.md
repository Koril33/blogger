# 页面设计

新版采用浅色纸面和蓝色强调色，深色主题使用对应的背景、正文、边框和强调色变量。中文正文优先使用系统字体，不下载字体；统一导航、面包屑、页脚和主题按钮由 `base.html` 提供，减少三个页面之间的漂移。默认品牌为 `DJHX BLOG`，面包屑从“首页”开始；搜索使用本地 SVG 放大镜。

## 页面层级

- 分类页直接展示双列卡片，窄屏变成单列。分类与文章有不同标签，文章优先展示作者标题、摘要和日期；不增加页面大标题、箭头或分类说明占位文字。
- 文章页突出标题与摘要。宽屏目录固定在正文左侧，正文最大阅读宽度受布局约束；窄屏目录移到正文前，使用可折叠 `details`。
- 归档按年份组织，日期和标题按行排列；列表上方用简短文字显示文章总数，各年份保留数量，不增加大标题或行尾箭头。无日期文章单独分组。长标题自动换行，草稿标签不挤压为不可读宽度。
- “未完成”使用独立的暖色标记，文章页增加说明，保持正文内容和标题本身不变。

## 阅读体验

代码高亮在构建时用 Pygments 生成，CSS 随站点一起发布；不加载 Tailwind CDN 或 highlight.js CDN。主题脚本在样式加载前读取偏好，减少闪烁；存储不可用时不会阻止页面加载。保留旧 `localStorage.theme` 作为读取兼容，新选择写入 `blogger-theme`。

图片限制为正文宽度，保留比例并启用 lazy/async；表格和代码块在自身容器横向滚动，避免拉宽整页。代码复制仅在支持 Clipboard API 的安全上下文显示，失败给出反馈；复制内容不含按钮文字。

没有 JavaScript 时正文、归档、目录、搜索表单仍可用。主题遵从 CSS 的默认浅色，切换按钮隐藏。导航可用键盘操作，有可见焦点、跳到正文链接、搜索标签和主题状态；尊重 `prefers-reduced-motion`。

CSS 的主要断点为 900px / 700px / 380px。重点检查长中文标题、长英文代码、透明图片、宽表格、移动端搜索框与归档草稿标签。

## 可修改位置

| 文件 | 职责 |
| --- | --- |
| `static/template/base.html` | 导航、元标签、共享结构 |
| `article.html` | 标题、日期、草稿提示、正文与目录 |
| `category.html` | 分类/文章卡片 |
| `archive.html` | 年份与文章行 |
| `static/css/site.css` | 主题变量、排版、布局、响应式 |
| `static/js/theme.js` | 首屏主题初始化 |
| `static/js/site.js` | 主题切换、复制和目录观察 |

站点标题、说明、搜索入口、关于地址、页脚和部署子路径优先通过 TOML 配置，普通用户不需要修改包内模板。
